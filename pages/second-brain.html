SECOND BRAIN

    Import, export & restore

    Import .txt or .md files. Each file becomes one note and keeps its filename. The text is copied into the note so it can be searched.

    PDFs, photos and Word documents can't be read yet — they'll be listed as not imported. Keep originals in OneDrive or Google Drive and paste a link into a note instead.

      Backup. Export saves every note to a file. Restore adds notes from a file — it never deletes notes you already have; if a note is in both, the newer edit is kept.
